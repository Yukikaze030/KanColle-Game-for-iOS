## 当前 P1 功能范围

- 原生 SwiftUI 入口、系统 Keychain 凭证、DMM/OOI/kancolle.moe 登录自动化。
- WKWebView + 本地 CONNECT 代理；仅游戏域名启用 CA MITM。
- 磁盘资源缓存、304 重校验、内置资源替换、gadget 绕行。
- 默认 Canvas 省内存渲染，可切换 WebGL；WebGL context lost/restored 监听。
- 登录成功检测后锁定横屏，网页杂项隐藏，游戏区域等比例全屏。
- 悬浮球及舰队/战斗/任务/工具/设置入口；P1 操作为截图、静音、刷新、退出。
- KC3/kcwiki 字幕数据、语音匹配与顶部字幕条。
- 原生内存监测、阈值弹窗、WebContent 终止恢复和诊断信息。

舰队数据、通知、小组件属于 P2；战斗预测与任务追踪属于 P3，按总规格后续阶段继续实现。
